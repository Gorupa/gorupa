## 🚀 Flagship Project — Vaad Case Tracker

<div align="center">

### ⚡ Vaad v2.1 — *The Dharma Update*

**`LIVE ON GOOGLE PLAY STORE`**

[![Download on Google Play](https://img.shields.io/badge/Google%20Play-Download%20Now-414141?style=for-the-badge&logo=google-play&logoColor=white)](https://play.google.com/store/apps/details?id=dev.pages.vaad.twa)
[![Open Web App](https://img.shields.io/badge/🌐%20Web%20App-vaad.pages.dev-4f46e5?style=for-the-badge)](https://vaad.pages.dev)

</div>

**Vaad** is a lightning-fast Indian court case tracker powered by the **eCourts India API** — built for lawyers, litigants, and legal professionals who need instant, reliable access to case status without bloat, ads, or friction.

Version **2.1 — The Dharma Update** marks a transformational leap from a utility app to a **full legal productivity platform**:

| Feature | Description |
|---|---|
| 🧠 **Ask Vaad AI** | Integrated legal chatbot trained on Indian law, including the **Bharatiya Nyaya Sanhita (BNS)**. Get instant, context-aware answers. |
| 📄 **AI Order Summaries** | Automatically extracts **Key Findings** and the **Next Hearing date** from court-issued PDFs. No more manual reading. |
| 💼 **Practice Ledger** | A dedicated fee tracker for advocates — manage collections, outstanding dues, and client billing from one place. |
| ⚡ **eCourts API** | Real-time case data across High Courts and District Courts nationwide. |
| 🔒 **Privacy-First** | No accounts. No tracking. No ads. Ever. |

> **The Dharma Update** is not just a feature release — it is a commitment to making Indian legal infrastructure accessible to every citizen.
